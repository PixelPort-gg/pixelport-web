Use a game's **Report a problem** action to send evidence about a problem in
Pixel Port 0.5.1. **In-app reports do not receive replies.** For answers, ask
in the **Help** forum on the [Pixel Port Discord](https://discord.gg/2eQah8DjK6).
Start with the [recovery guide](/docs/known-issues/) if you need help identifying
the failed step.

## Choose a Discord forum

After joining the server, choose the forum for what you need:

| Forum | Use it for |
| --- | --- |
| **Help** | [A problem you need help with](#ask-for-help-in-discord), such as setup, installation, a crash, or an input issue. |
| **Game reports** | [Your first-hand gameplay result](#share-a-gameplay-report), including what worked and any limits. |
| **Game requests** | [A game you want to try](#request-a-game), identified by its Steam store link or App ID. |

If a game is available but fails to install or run, use **Help**. Include the
details below so the problem can be understood without guessing your setup.

## Report a problem in the app

1. Open the affected game's page and choose **Report a problem** from its
   menu or help area.
2. Describe what you did, what you expected, and what happened. Include the
   error text and whether the problem concerns installation, startup, or gameplay.
3. Contact is optional. You can leave the email or Discord handle field blank.
   Filling it in does not bring a reply; use Discord **Help** for answers.
4. Choose whether to attach the privacy-scrubbed diagnostic log, then choose
   **Send**.

The form stays open while sending. If it says **Delivery wasn't confirmed**,
retry or use **Open Discord**. Do not treat a failed send as a received report.
A successful submission is not a promise that the problem has been resolved.

## Review a diagnostic report

After some failures, Pixel Port offers a diagnostic preview. Review its
contents before deciding whether to send it. This is separate from a support
message and its optional log attachment. A diagnostic upload does not provide
a contact for a reply. Sending one support message does not enable ongoing
optional telemetry.

## Ask for help in Discord

Open a post in **Help** with the game or affected setup step in the title.
Describe the problem and include the versions and conditions listed below.
Keep follow-up details in the same post. If a reply asks for a check, report
what you tried and what changed. Follow any link to an existing discussion
so related results stay together.

## What to include when asking for help

- Game title and Steam store link or App ID, if applicable.
- Pixel Port version, plus the installed runtime version shown under
  **Settings → Prism Runtime**.
- Mac chip, memory, and macOS version.
- Selected runtime, graphics backend, and installed copy, if known.
- Steps to reproduce, exact error, and whether you reached a menu or actual gameplay.
- Any workaround tried and its result. For input or audio issues, include the
  controller or audio-device model and connection.

Describe unknown settings as unknown. Do not guess them. Before posting public
screenshots or logs, remove personal details, account information, and credentials.

## Share a gameplay report

In **Game reports**, use the forum's report template to describe what you
personally tested. Include:

- The game and Steam store link or App ID.
- Pixel Port version, runtime and graphics settings, Mac chip and memory,
  and macOS version.
- The test date, how long you played, and the gameplay or mode you tested.
- Any required tweaks, broken features, crashes, or other limits.

If you only reached a menu, say so. Do not describe untested modes as working
or copy another player's result as your own. A report can help inform
compatibility information, but posting one does not guarantee a label change
or qualify the game for every Mac.

## Request a game

If a game's page offers **Request**, use it to record interest. A request does
not promise availability, compatibility, a personal notification, or a date.
To request a game in Discord, open a post in **Game requests**. Include the
Steam store link or App ID and the exact game or edition you mean. Check
whether the game is already available before posting. If it is available
but something fails, use **Help** with the failure details.

A reply that a game is available means you can try it. Unlocking does not
prove gameplay compatibility or promise that an existing problem is fixed.
